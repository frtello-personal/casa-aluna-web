# PayU Integration (Phase 2)

This directory will contain PayU payment integration for Colombian market.

## Features (Coming in Phase 2)
- PayU checkout flow
- Secure payment processing
- Support for Colombian payment methods (PSE, credit/debit cards)
- COP currency handling
- Installment payments (cuotas)

## Configuration
Environment variables required:
- `PAYU_MERCHANT_ID`
- `PAYU_API_KEY`
- `PAYU_ACCOUNT_ID`
- `PAYU_TEST_MODE`
